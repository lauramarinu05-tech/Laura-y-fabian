APUNTES DISEÑO PAGINA WEB

. Crear un sitio web local.

1. Creamos una carpeta en ESO(U:) con nuestro nombre y apellidos, sin espacios, evitando en lo posible poner eñes, ni diéresis y con el siguiente formato: 1erApellido2oApellidoNombre. Es decir, si mi nombre es “Pedro Nuñez D'aqüino”, escribiré el siguiente nombre de carpeta “NunezDaquinoPedro” Esta carpeta a partir de ahora, será nuestra carpeta RAIZ o carpeta principal. 2. Dentro de la carpeta anteriormente creada crearemos las siguientes subcarpetas para empezar: Las páginas HTML se guardarán en el directorio o carpeta principal mientras que los elementos que utilizan (audios, vídeos, hojas de estilo, imágenes, etc) se situarán en las subcarpetas correspondientes. Si se quiere crear más carpetas para crear un sitio web más completo, aquí tenéis una descripción y ejemplos. Esta organización está especialmente pensada para un sistema de páginas HTML que comparten recursos: imágenes, hoja de estilo, javascript, etc. Las principales carpetas que utiliza son:  audios: archivos de audio mp3.  css: hojas de estilo css.  descargas: archivos zip, exe, etc que se ofrecen para descarga.  images: imágenes jpg, gif o png.  pdf: documentos pdf.  scripts: archivos js con código javascript reutilizable.  swfs: archivos animaciones flash (*.swf).  vídeos: ficheros en distintos formatos de vídeo: *.wmv, *.flv 3. Importante. Si no se tiene acceso a ESO(U:), se pueden realizar los pasos anteriores en el disco duro del ordenador que estés usando. Posteriormente se copia la carpeta o directorio principal a ESO(U:).
